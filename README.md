## 📱 Mobile OS

### 🍎 iOS (iPhone / iPad)

> **Заметка:** Загружайте профиль исключительно через нативный **Safari** — движок WebKit напрямую передает профиль в системный установщик.

1. Откройте в Safari прямую ссылку на профиль: [xbox-dns.mobileconfig](http://xbox-dns.ru/ios/xbox-dns.mobileconfig).
2. Подтвердите диалоговое окно «Разрешить загрузку».
3. Перейдите в **Настройки** системы — в самом верху нажмите на появившийся баннер **«Профиль загружен»**.
4. Нажмите **Установить** в верхнем углу и введите код-пароль устройства.

---

### 🤖 Android (9+)

1. Перейдите в **Настройки** ➔ **Подключения** (или **Сеть и интернет**).
2. Выберите **«Другие настройки»** ➔ **«Частный DNS»** *(Private DNS)*.
3. Переключите режим на **«Имя хоста поставщика»**.
4. Введите хост:  
   `xbox-dns.ru`
5. Сохраните изменения.

---

## 💻 Desktop & Browsers

### 🌐 Изолированный веб-серфинг (Chrome / Firefox / Edge / Yandex)

> Идеально для работы с Gemini: перенаправляет только запросы в браузере, не затрагивая трафик системы, мессенджеров и игр.

* **Chromium (Chrome, Edge, Яндекс, Opera):**
  1. **Настройки** ➔ **Конфиденциальность и безопасность** ➔ **Безопасность**.
  2. Активируйте переключатель **«Использовать безопасный DNS-сервер»**.
  3. Выберите пункт **«С другим поставщиком»** и вставьте URL:  
     `https://xbox-dns.ru/dns-query`

* **Mozilla Firefox:**
  1. **Настройки** ➔ **Приватность и защита** ➔ блок **«DNS через HTTPS»**.
  2. Включите режим **«Максимальная защита»**.
  3. В списке поставщиков укажите **«По выбору»** и введите URL:  
     `https://xbox-dns.ru/dns-query`

---

### 🪟 Windows 11 (System DoH)

1. Откройте **Параметры** (`Win + I`) ➔ **Сеть и Интернет** ➔ выберите текущую сеть (**Wi-Fi** или **Ethernet**).
2. В строке **«Назначение DNS-сервера»** нажмите кнопку **«Изменить»**.
3. Переключите режим на **Вручную** и включите тумблер **IPv4**:
   * **Предпочтительный DNS:** `111.88.96.50`
   * **Дополнительный DNS:** `111.88.96.51`
4. В поле **«Шифрование DNS»** выберите **«Только шифрование (DNS через HTTPS)»** и вставьте:  
   `https://xbox-dns.ru/dns-query`
5. Нажмите **Сохранить**.

---

### 🪟 Windows 10 (Legacy IPv4)

1. Нажмите `Win + R`, введите `ncpa.cpl` и нажмите **Enter**.
2. Правый клик по сетевому адаптеру ➔ **Свойства**.
3. Выберите строку **«IP версии 4 (TCP/IPv4)»** ➔ нажмите **Свойства**.
4. Активируйте пункт **«Использовать следующие адреса DNS-серверов»**:
   * **Основной:** `111.88.96.50`
   * **Альтернативный:** `111.88.96.51`
5. Сохраните по кнопке **ОК**.

## 🛠️ Debug & Healthcheck

* **Статус туннеля:** перейдите на страницу проверки [xbox-dns.ru/test](https://xbox-dns.ru/test).
* **Сброс системного DNS-кэша (Windows):** при задержках или старых маршрутах выполните в консоли:
  ```cmd
  ipconfig /flushdns
  ```
  После выполнения перезапустите браузер.
