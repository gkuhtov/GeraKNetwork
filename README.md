# 🌐 Gemini & Xbox DNS Setup

> Быстрая настройка DoH / DoT профилей для обхода региональных ограничений Google Gemini и сервисов Xbox.

---

### ⚡ Быстрые параметры подключения

* **DoH URL (Браузеры / Windows 11):**  
  `https://xbox-dns.ru/dns-query`
* **DoT Host (Android Частный DNS):**  
  `xbox-dns.ru`
* **Основной IPv4:**  
  `111.88.96.50`
* **Дополнительный IPv4:**  
  `111.88.96.51`
* **iOS Профиль:**  
  [Скачать xbox-dns.mobileconfig](http://xbox-dns.ru/ios/xbox-dns.mobileconfig)

---

## 📱 Мобильные устройства

### 🍏 iOS (iPhone / iPad)

> **Важно:** Загрузку необходимо выполнять строго через **Safari**. Сторонние браузеры не имеют системного доступа к установке профилей iOS.

1. Откройте в Safari ссылку: [xbox-dns.mobileconfig](http://xbox-dns.ru/ios/xbox-dns.mobileconfig)
2. Нажмите **Разрешить** во всплывающем окне загрузки.
3. Откройте системные **Настройки** — сверху появится пункт **«Профиль загружен»**.
4. Нажмите **Установить** в верхнем правом углу и введите код-пароль устройства.

---

### 🤖 Android (версия 9 и новее)

1. Перейдите в **Настройки** → **Подключения** (или **Сеть и интернет**).
2. Откройте пункт **«Другие настройки»** → **«Частный DNS»** (Private DNS).
3. Выберите пункт **«Имя хоста поставщика частного DNS»**.
4. Введите хост:  
   `xbox-dns.ru`
5. Нажмите **Сохранить**.

---

## 💻 Компьютеры и браузеры

### 🌐 Настройка только в браузере (Chrome / Edge / Яндекс / Firefox)

> Этот метод направляет через безопасный DNS только вкладки браузера, не затрагивая остальные программы и пинг в играх.

* **Chromium (Chrome, Edge, Яндекс.Браузер, Opera):**
  1. **Настройки** → **Конфиденциальность и безопасность** → **Безопасность**.
  2. Включите пункт **«Использовать безопасный DNS-сервер»**.
  3. Выберите **«С другим поставщиком»** и вставьте:  
     `https://xbox-dns.ru/dns-query`

* **Mozilla Firefox:**
  1. **Настройки** → **Приватность и защита** → раздел **«DNS через HTTPS»**.
  2. Выберите режим **«Максимальная защита»**.
  3. В списке поставщиков укажите **«По выбору»** и введите:  
     `https://xbox-dns.ru/dns-query`

---

### 🪟 Windows 11 (Системный DoH)

1. Откройте **Параметры** (`Win + I`) → **Сеть и Интернет** → выберите активную сеть (**Wi-Fi** или **Ethernet**).
2. В строке **«Назначение DNS-сервера»** нажмите **Изменить**.
3. Переключите режим на **Вручную** и включите **IPv4**:
   * Предпочтительный DNS: `111.88.96.50`
   * Дополнительный DNS: `111.88.96.51`
4. В поле **«Шифрование DNS»** выберите **«Только шифрование (DNS через HTTPS)»** и вставьте:  
   `https://xbox-dns.ru/dns-query`
5. Нажмите **Сохранить**.

---

### 🪟 Windows 10 (Классический IPv4)

1. Нажмите сочетание клавиш `Win + R`, введите `ncpa.cpl` и нажмите **Enter**.
2. Правый клик по активному адаптеру сети → **Свойства**.
3. В списке выделите строку **«IP версии 4 (TCP/IPv4)»** и нажмите **Свойства**.
4. Активируйте **«Использовать следующие адреса DNS-серверов»**:
   * Основной: `111.88.96.50`
   * Альтернативный: `111.88.96.51`
5. Нажмите **ОК** для сохранения.

---

## 🔍 Диагностика

* **Проверка работы:** перейдите на страницу теста [xbox-dns.ru/test](https://xbox-dns.ru/test).
* **Сброс кэша при сбоях (Windows):** выполните в терминале (CMD / PowerShell) команду `ipconfig /flushdns` и перезапустите браузер.
